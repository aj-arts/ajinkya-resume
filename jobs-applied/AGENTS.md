# Agent Instructions

Files under `jobs-applied/` are application audit records.

When adding a new application:
- Create a folder named `<company>-<role-slug>/`.
- Preserve submitted PDFs, screenshots, notes, source URLs, and confirmation or blocker evidence.
- If the resume was tailored for this job, keep the tailored `.tex` and its compiled `.pdf` in this folder. The master resume at the repo root must stay untailored.
- Update `jobs-applied/README.md`.

Do not delete or overwrite submitted application records unless the user explicitly asks for cleanup.
